# Bitcoin Ghost Multiplayer Game 👻₿

> Also in this repo: **[Midship Drift](drift/)**, an arcade sprite-scaling racer starring Leo's MR2. Open `drift/index.html` to play, or `drift2/index.html` for version 2 with pre-rendered sprites.

A real-time multiplayer game inspired by Google's Halloween 2018 Doodle, but with a Bitcoin theme!

## 🎮 How to Play

- **Collect bitcoins** to build your trail
- **Steal from opponents** by touching their trail
- **Return to your base** to score points
- **2-minute competitive matches**

## 🚀 Features

- Real-time multiplayer with WebSocket
- Trail stealing mechanics
- Server-authoritative gameplay
- Matchmaking system
- Performance optimized for smooth gameplay

## 🛠️ Local Development

```bash
npm install
npm start
```

Open `http://localhost:3001` in two browser tabs to play!

## 🎯 Game Mechanics

- **Mouse/WASD controls** - Move your bitcoin ghost
- **Trail building** - Collected bitcoins follow behind you
- **Trail stealing** - Touch opponent's trail to steal their bitcoins
- **Strategic gameplay** - Risk vs reward with longer trails
- **Base scoring** - Return to your colored base to score points

Built with Node.js, Socket.io, and HTML5 Canvas.
